# School Projects

This repository contains small school projects and experiments created while learning web development.

## Projects

### Wykre Guanta
A Gantt chart application for planning tasks and assigning responsible people.

Features:
- Select a project path
- Add new tasks with duration in days
- Assign tasks to people
- Visualize work progress in a Gantt-style chart
- Built with HTML, CSS, and JavaScript

Project location:
- `Wykre Guanta/v1.1/`

### Project WebSite
A PHP project for managing and publishing school project submissions.

Project location:
- `Project WebSite/`

Live site:
- https://zinchukmaksym.infinityfreeapp.com

## Tech stack
- HTML
- CSS
- JavaScript
- PHP

## Run locally
1. Open `Wykre Guanta/v1.1/index.html` in a browser.
2. Or serve the folder with a local web server if preferred.
